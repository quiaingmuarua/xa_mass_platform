# example 目录

Status: current local package example note.

## 📖 说明

本目录包含 channel 各子模块的典型用法和最佳实践示例，覆盖消息流、队列、事件总线、传输器等多种场景。

---

## 🚀 典型用法

- 消息流/队列的创建、注册、消费、ack
- 事件总线的注册、发布、监听、注销
- 传输器/桥接器的集成示例

---

## 🏃 如何运行

- 可直接在 IDE 中运行 main 方法
- 或参考 test 目录下的单元测试用例
