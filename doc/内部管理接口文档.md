# XA Mass Platform 内部管理接口文档

> 本文档用于梳理和规划网关/消息平台的内部管理与监控接口，便于后续逐步实现和维护。

---

## 1. 队列监控

- **接口说明**：获取 input/output 队列长度、堆积等状态
- **路径**：`GET /api/queue/status`
- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "inputQueue": 12,
    "outputQueue": 5
  }
}
```

---

## 2. Session 管理

- **接口说明**：获取所有在线 Session/device 详情
- **路径**：`GET /api/session/list`
- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "deviceId": "dev123",
      "role": "USER",
      "ip": "192.168.1.10",
      "connectedAt": 1688000000000
    }
  ]
}
```

---

## 3. 连接统计

- **接口说明**：统计当前总连接数、在线/离线设备数
- **路径**：`GET /api/session/stats`
- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "total": 100,
    "online": 80,
    "offline": 20
  }
}
```

---

## 4. 广播/点发消息

- **接口说明**：主动推送消息到指定 device/role
- **路径**：`POST /api/message/send`
- **参数示例**：

```json
{
  "deviceId": "dev123",
  "role": "USER",
  "content": "hello"
}
```

- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok"
}
```

---

## 5. 消息速率/统计

- **接口说明**：近 1min/5min 消息数、处理耗时等
- **路径**：`GET /api/metrics`
- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "msgPerMin": 1200,
    "msgPer5Min": 6000,
    "avgProcessTimeMs": 8.5
  }
}
```

---

## 6. 健康检查

- **接口说明**：网关节点健康状态
- **路径**：`GET /api/health`
- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "status": "UP",
    "timestamp": 1688000000000
  }
}
```

---

## 7. 调试接口

- **接口说明**：原始 Envelope 调用，便于调试
- **路径**：`POST /api/debug/sendRaw`
- **参数示例**：

```json
{
  "rawJson": "{...}"
}
```

- **返回示例**：

```json
{
  "code": 0,
  "msg": "ok"
}
```

---

> 后续可根据实际需求补充更多接口，如队列明细、消息重发、异常追踪等。
