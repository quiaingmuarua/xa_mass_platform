# XA Mass Platform 启动流程说明

## 1. 启动入口

项目采用 Spring Boot，服务端启动入口为  
`xa-mass-mock/src/main/java/com/xa/mass/mock/runner/WebSocketServerStarter.java`  
该类实现了 `CommandLineRunner`，在 `@Profile(\"server\")` 下自动执行。

---

## 2. 核心启动流程

### 2.1 队列与上下文初始化

- 通过 Spring 注入 `inputQueue` 和 `outputQueue`。
- 获取全局单例的 `ServerSessionManager`。
- 创建 `Gson` 实例。
- 构造 `DispatcherContext`，统一封装队列、会话、序列化等运行时依赖。

### 2.2 注册消息处理器（Handler）

- 可通过 `MassServerBuilder.registerHandler(project, MessageType, subMsgType, handler)` 注册**项目级** handler。
- 也可通过 `registerHandler(MessageType, subMsgType, handler)` 注册**全局** handler。
- 查找时会优先 project 级，无则降级全局。

### 2.3 MassServerBuilder 构建服务

- 通过链式 API 配置端口、WebSocket 路径、上下文、handler、中间件等。
- 例如：
  ```java
  MassServerConfig serverConfig = MassServerBuilder.create()
      .withPort(18088)
      .withWebSocketPath("/ws")
      .withDispatcherContext(dispatcherContext)
      .registerHandler("WhatsApp", MessageType.TASK, "", taskHandler)
      .registerHandler(MessageType.PING, "", pingHandler) // 全局
      .withDefaultMiddlewares(true)
      .build();
  ```

### 2.4 MassServerStater 启动服务

- 通过 `new MassServerStater(serverConfig).start();` 启动服务。
- 内部自动创建并启动 `WebSocketServerImpl`，监听端口，处理消息。

---

## 3. 消息分发与处理机制

### 3.1 消息流转

- 消息通过队列流转，经过中间件链（如 EnvelopeMiddleware）。
- 最后一环自动调用 `MessageHandlerRegistry` 查找并执行 handler。

### 3.2 Handler 查找优先级

- 先查 project 级（如 WhatsApp/TG 特有）。
- 无则查全局（如 PING/PONG/通用 handler）。

### 3.3 Handler 注册 API

- `registerHandler(project, type, subType, handler)` —— 注册到指定 project。
- `registerHandler(type, subType, handler)` —— 注册到全局（project=null）。

---

## 4. 设计点评

- **高内聚、低耦合**：各核心组件职责清晰，依赖通过上下文传递，易于维护和扩展。
- **统一的 Handler Registry**：支持多项目/多租户，查找优先级灵活，注册 API 简单直观。
- **中间件机制**：支持灵活插拔、扩展消息处理流程。
- **易于测试和多实例部署**：每个服务实例拥有独立的 handler 注册表，互不干扰。

## 5. 典型启动代码示例

```java
@Component
@Profile("server")
public class WebSocketServerStarter implements CommandLineRunner {
    @Autowired @Qualifier("outputQueue") MessageQueue<Envelope> outputQueue;
    @Autowired @Qualifier("inputQueue") MessageQueue<Envelope> inputQueue;
    ServerSessionManager sessionManager = ServerSessionManager.INSTANCE;
    private Gson gson = new Gson();

    @Override
    public void run(String... args) {
        DispatcherContext dispatcherContext = new DispatcherContext(inputQueue, outputQueue, sessionManager, gson);

        MassMessageHandler taskHandler = msg -> { /* ... */ return new ArrayList<>(); };

        MassServerConfig serverConfig = MassServerBuilder.create()
            .withPort(18088)
            .withWebSocketPath("/ws")
            .withDispatcherContext(dispatcherContext)
            .registerHandler("WhatsApp", MessageType.TASK, "", taskHandler)
            .withDefaultMiddlewares(true)
            .build();

        new MassServerStater(serverConfig).start();
    }
}
```
